# Homem support

Homem is an independent native Memoh client for iPhone and iPad. It supports the official Memoh service and compatible third-party servers.

## Get connected

For the official service, choose **Sign in to Memoh** and enter the code sent to your email. Choose **Continue in browser** for the official website's other sign-in options. For another server, expand **Use another server**, enter its complete API base URL and your credentials, then connect.

## Desktop and terminal

Your server must provide a running agent workspace and the necessary permissions. In a conversation, the split-view button opens a desktop or terminal above chat. Desktop split view starts in view-only mode. Switch to control mode only when you want to interact with the remote desktop. Use the reconnect button after a connection interruption.

## Accounts and data

You can save multiple accounts on different servers. Removing an account from Homem removes its saved local credentials and drafts; it does not delete data on the server. Contact your server operator for server access, billing, data deletion, model configuration, or workspace availability.

## Contact support

Email [support@ieb.app](mailto:support@ieb.app) for help with Homem. Reports should include the Homem version, iOS version, affected feature, and any non-sensitive error text. Do not send passwords, access tokens, verification codes, or private conversation content.

## Save a file from another app

After updating, open Homem once. In Files, Photos, or another app, choose Share → Homem. Select a saved account, a workspace where available, and an agent, then tap Save to workspace. The files appear in a new Shared-… folder in the agent’s Files view. Keep the sheet open until it reports success. If some files fail, retry the remaining files. Up to 20 files can be shared at a time, each up to 50 MB.
